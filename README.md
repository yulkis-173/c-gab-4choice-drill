# C-GAB 4択ドリル

C-GABの解答集をもとにした、4択の予想問題ドリルです。

- 言語197問（精選178＋追加19）
- 非言語240問（精選97＋自動143）
- 英語精選143問
- 英語全問556問（元データのQ&Aを4択化）

アプリ版は全部で1,136問。選択肢をクリックすると、その場で正解・不正解と解説が出ます。間違えた問題は数問後に再出題されます。学習記録はブラウザの localStorage に保存されます。

## 使い方

公開URLをスマホのSafariで開き、必要なら「ホーム画面に追加」してください。

- 範囲：全部／言語／非言語／英語／英語（全問）
- 解き方：全問／未回答だけ／間違えた問題／苦手順
- 出題順：シャッフル／番号順

## 注意

- 言語・英語の公式形式は本来A/B/Cの3択です。本アプリは4択で練習するために再構成しています。
- 非言語の数値・資料は練習用の予想問題です。正解の数値・語句は解答集の記載を保持しています。
- 「自動（要確認）」ラベルが付いた問題は、元メモを機械的に4択化したものです。
