# C-GAB 判定ドリル

C-GABの解答集をもとにした判定ドリルです。

**X（解答集の設問）は原文のまま。Y（解答）だけを選択肢化しています。**

- 言語388問：X 1つにつき3択。A「本文から導き出せる」／B「導き出せない・矛盾」／C「どちらとも言えない」
- 非言語251問：X 1つにつき4択。数値は 5.3 → 0.53／53／530 のように形を変えて誤答を作成
- 英語570問：X 1つにつき4択。Y＋他の設問のYを誤答に使用

合計1,209問。選択肢をクリックすると、その場で正解・不正解と解説が出ます。間違えた問題は数問後に再出題されます。学習記録はブラウザの localStorage に保存されます。

## 使い方

公開URLをスマホのSafariで開き、必要なら「ホーム画面に追加」してください。

- 範囲：全部／言語／非言語／英語
- 解き方：全問／未回答だけ／間違えた問題／苦手順
- 出題順：シャッフル／番号順

## 注意

- 問題文（X）の書き換え・本文の推論・図表データの再構成はしていません。
- 誤答選択肢だけを、解答形式に合わせて機械的に生成しています。
- 解答集には途中で切れているメモやOCR表記ゆれがあります。Xはその原文をそのまま使っています。
